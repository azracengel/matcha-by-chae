# How this site is built

- This is a static website built with HTML and CSS. Do not add frameworks, npm, a build step, or a server.
- Shared styles belong in `styles.css`, and every HTML page should link to this stylesheet.
- Build only the Home, About, Menu, and Visit pages described in `PRD.md`. Ask before adding another page or section.
- Use only client-approved content and assets. Do not invent menu items, prices, hours, contact information, or brand details.
- Keep the website responsive and easy to use on both desktop and mobile. Keep file and folder names lowercase with hyphens and no spaces.
